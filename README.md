# quant_reactor_ultra

A Streamlit-based, ultra-modular research lab for:

- Comparing performance across multiple CSVs
- Building ranking tables
- Adding regime and volatility filters
- Constructing portfolio equity curves
- Computing win-rate, expectancy, and average R multiple

## Quickstart

1. Install dependencies:

   \\\ash
   pip install -r requirements.txt
   \\\

2. Run locally:

   \\\ash
   streamlit run streamlit_app.py
   \\\

3. Deploy to Streamlit Cloud using this GitHub repo.
